# LearnShiz Website

This is the front-end repository for the LearnShiz Techies public website.

## Overview

LearnShiz Techies is a global, developer-first staffing partner for modern engineering & AI teams.
This website showcases our AI-powered talent matching, vetting process, and career opportunities.

## Tech Stack

- React
- Vite
- Tailwind CSS
- React Router DOM

## Getting Started

To run the project locally:

```bash
npm install
npm run dev
```

The site will be available on `http://localhost:5173`.
